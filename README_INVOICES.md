# نظام الفواتير والمدفوعات - Yassin Admin System

## نظرة عامة

تم تطوير نظام الفواتير والمدفوعات لضمان إنشاء فواتير ومدفوعات تلقائيًا عند إنشاء طلبات العملاء. هذا يحل المشكلة التي كانت موجودة سابقًا حيث كان العملاء لديهم طلبات ولكن لا توجد فواتير أو مدفوعات مرتبطة بها.

## المميزات الرئيسية

1. **إنشاء تلقائي للفواتير**: عند إنشاء طلب جديد، يتم إنشاء فاتورة تلقائيًا مرتبطة بهذا الطلب.
2. **إنشاء تلقائي للمدفوعات**: عند اكتمال الطلب، يتم إنشاء سجل دفع تلقائيًا مرتبط بالفاتورة.
3. **تحديث حالة الفواتير**: عند تغيير حالة الطلب، يتم تحديث حالة الفاتورة المرتبطة تلقائيًا.
4. **عرض الفواتير والمدفوعات**: يمكن للمستخدمين عرض الفواتير والمدفوعات في صفحة تفاصيل العميل.
5. **مزامنة يدوية**: يمكن للمستخدمين مزامنة الفواتير والمدفوعات يدويًا لعميل معين.

## هيكل قاعدة البيانات

### جدول الفواتير (customer_invoices)
- `id`: معرف الفاتورة
- `invoice_number`: رقم الفاتورة (فريد)
- `customer_id`: معرف العميل
- `order_id`: معرف الطلب
- `amount`: المبلغ الأساسي
- `tax_amount`: مبلغ الضريبة
- `total_amount`: المبلغ الإجمالي
- `status`: حالة الفاتورة (pending, paid, partially_paid, cancelled, overdue)
- `due_date`: تاريخ الاستحقاق
- `notes`: ملاحظات
- `created_at`: تاريخ الإنشاء
- `updated_at`: تاريخ التحديث

### جدول المدفوعات (customer_payments)
- `id`: معرف الدفعة
- `payment_number`: رقم الدفعة (فريد)
- `customer_id`: معرف العميل
- `invoice_id`: معرف الفاتورة
- `amount`: المبلغ المدفوع
- `payment_method`: طريقة الدفع (cash, transfer, credit_card, check, other)
- `payment_date`: تاريخ الدفع
- `reference_number`: رقم المرجع
- `notes`: ملاحظات
- `created_at`: تاريخ الإنشاء
- `updated_at`: تاريخ التحديث

## الملفات الرئيسية

1. **order_hooks.php**: يحتوي على الدوال التي تتعامل مع إنشاء الفواتير والمدفوعات تلقائيًا.
2. **process_order.php**: يتعامل مع إنشاء وتحديث وحذف الطلبات، ويستدعي دوال من order_hooks.php.
3. **sync_invoices.php**: يقوم بمزامنة الفواتير والمدفوعات لجميع الطلبات الموجودة.
4. **sync_customer_invoices.php**: يقوم بمزامنة الفواتير والمدفوعات لعميل معين.
5. **view_enhanced.php**: عرض تفاصيل العميل مع علامات التبويب للفواتير والمدفوعات.

## كيفية الاستخدام

### مزامنة الفواتير والمدفوعات لجميع العملاء

1. انتقل إلى `http://localhost/yassin-admin-system/modules/orders/sync_invoices.php`
2. سيتم عرض نتائج المزامنة مع عدد الفواتير والمدفوعات التي تم إنشاؤها.

### مزامنة الفواتير والمدفوعات لعميل معين

1. انتقل إلى صفحة تفاصيل العميل.
2. انقر على زر "مزامنة الفواتير" في الأعلى.
3. سيتم إعادة توجيهك إلى نفس الصفحة مع رسالة نجاح تعرض عدد الفواتير والمدفوعات التي تم إنشاؤها.

### عرض فواتير ومدفوعات العميل

1. انتقل إلى صفحة تفاصيل العميل.
2. انقر على علامة التبويب "فواتير العميل" أو "مدفوعات العميل".
3. سيتم عرض قائمة بالفواتير أو المدفوعات الخاصة بالعميل.

## الإعداد الأولي

لإعداد النظام لأول مرة، قم بزيارة:

1. `http://localhost/yassin-admin-system/setup_invoice_tables.php` - لإنشاء جداول الفواتير والمدفوعات.
2. `http://localhost/yassin-admin-system/setup_sample_data.php` - لإنشاء بيانات عينة للعملاء والطلبات والفواتير والمدفوعات.

## ملاحظات فنية

- يتم احتساب ضريبة القيمة المضافة بنسبة 15% تلقائيًا على جميع الفواتير.
- يتم تعيين تاريخ استحقاق الفاتورة بعد 15 يومًا من تاريخ إنشاء الطلب.
- عند اكتمال الطلب، يتم تغيير حالة الفاتورة إلى "مدفوعة" وإنشاء سجل دفع.
- عند إلغاء الطلب، يتم تغيير حالة الفاتورة إلى "ملغاة".
